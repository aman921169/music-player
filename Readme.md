Music Player
A simple desktop music player built with Python, CustomTkinter, and pygame-ce.
This project is being developed step by step to learn GUI development,
audio playback, event-driven programming, and basic application state management in Python.
Current Features
Select multiple audio files
Playlist support
Play selected songs
Play, pause, resume, and stop controls
Next song
Previous song
Volume control
Song duration display
Live playback progress
CustomTkinter GUI
Technologies Used
Python
CustomTkinter
pygame-ce

How to Run
Install the required libraries:
```bash
pip install customtkinter pygame-ce
```
Run the application:
```bash
python main.py
```
