
# Music Player

A simple desktop music player built with Python, CustomTkinter, and pygame-ce.

This project is being developed step by step to learn GUI development,
audio playback, and event-driven programming in Python.

## Current Features

- Select audio files
- Play music
- Pause music
- Resume music
- Stop music
- Volume control
- Playlist option
- CustomTkinter GUI

## Technologies Used

- Python
- CustomTkinter
- pygame-ce
- Git & GitHub
- CustomTkinter
